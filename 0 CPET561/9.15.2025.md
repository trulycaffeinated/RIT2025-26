# C Language Review
**Definition** - Place where a variable is created, assigned storage
**Declaration** - Nature of variable state is declared, but no storage is assigned. All variables must be declared
```C
int func_dec(void); /*function prototype*/
extern my_data;     /*declaration*/

int func_dec(void)
{
	float f_var;    /*a definition*/
	int counter;    /*another one*/
	int rand_num(void); /*declare but no define*/
	return(0);
}
```
