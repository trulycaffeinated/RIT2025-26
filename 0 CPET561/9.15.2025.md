# C Language Review
**Definition** - Place where a variable is created, assigned storage
**Declaration** - Nature of variable state is declared, but no storage is assigned. All variables must be declared
```C
int func_dec(void); /*function prototype*/
extern my_data;     /*declaration*/

int func_dec(void)
{
	float f_var;    /*a definition*/
	int counter;    /*another one*/
	int rand_num(void); /*declare but no define*/
	return(0);
}
```

//file2.c

C is case sensitive. CamelCase and camelcase are not the same in C.

**Scope**
- Part of the program within which a name can be used
- Largest region in which the name is valid
- Interrelated with the storage duration of identified object
	- Length of time an object remains in region of storage
**Visibility**
- Region of program text from which the object associated with the name can be legally accessed
- Scope can exceed visibility, but visibility cannot exceed scope
	- Ex: Object hidden by duplicate identified in inner declarative region

```C
//file.C
volatile int count = 0; //global

void bad_func(){
	int count; //local count - blocks global count
}
```

**Typedef**
- Used to create custom data type names
- names used with typedef are not new data types
	- Synonyms for data types it represents
- Object defined with typedef identifier are exactly the same as if the object were defined by explicitly with the identifier
- Can be used to reinforce concept of hardware and memory 
```C
typedef unsigned int     uint32;
typedef unsigned short   uint16;
```

### Preprocessor
Part of compiler
Processes file before compilation
Works on file line by line
Perform simple textual manipulation before passing modified text to compiler
- All occurrence of *\<name\>* replaced with value

**Preprocessor  Statements**
- \#include
- \#define
	- \#ifndef
	  \#define
	  \#endif
- \#if

**Type Qualifier**
Something used in addition to data type to better define how variable will be used
- Volatile - other files can access global variable - or inputs are changing outside processor control (keypad, switches, etc)
```C
volatile int *push_button = PUSH_BUTTON_BASE_ADDRESS;
```
- Const
- Static - will not move generally  - limits visibility to inside current file
	  Static functions - not going anywhere - only visible inside of that file
	  Static variables - value is held

```C
//A
uint8_t Var1 = 0;
void test_function(void){
	uint8_t Var2 = 0;
	
	Var1++;
	Var2++;
	//Var2 is reset to 0 each call	
}
/*-------------------------------------------------------------*/
//B
uint8_t Var1 = 0;
void test_function(void){
	static uint8_t var2 = 0;
	
	Var1++;
	Var2++;
	//Var2 value is held each call. Only set to 0 on entry
}
```
