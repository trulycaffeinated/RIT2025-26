# Direct Memory Access (DMA)

Mechanism for transferring data directly to/from memory and/or IO without involving processor
Requires the use of a DMAC (DMA Controller)

**Programmed I/O** - uses input and output instructions (processor) to transfer data between devices
- Data transfer can be under program or interrupt control
Advantage 
- Simple to implement
Disadvantage
- Processor is tied up transferring data
- Poor utilization of processor

**DMAC**
- Special hardware controller for data transfer (offloads work from processor)
- Takes place of processor in data transfers
- Performs all bus operations
Advantages
- Allows data transfer w/o processor
- Increases system performance
Disadvantages
- More complex
- requires specialized hardware

Processor must provide the following to the DMAC
- Source address
- Destination address
- start indicator (bit)
- number of bytes being transferred

1. Program the DMAC
2. Start the transfer
3. Request the bus (processor may be using it)
4. Issue the addresses
5. Transfer the data
6. Update the addresses
7. Update the processor (interrupt)
