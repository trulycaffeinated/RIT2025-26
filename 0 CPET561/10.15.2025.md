# Interfacing with Memory
Memory in code looks like an array
Memory physically is inferred RAM - specialized RAM blocks are used which are not registers

**Memory Mapped** - specific devices that have a register map inside your memory
- Switches
- Pushbuttons
They have a dedicated location in memory where you can access those interfaces/base address
Need to use C Pointer to point to base address, and then offset to communicate to all other locations

**Full Address Decoding**
Using all the address bits to decode a memory device
uses more hardware to decode all address
no aliases of emor
