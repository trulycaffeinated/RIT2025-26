# Input/Output Programming
**I/O Devices** - what are they?
- Provide info to the processor or receive information from the processor
	- can be subdivided into input and output
	- keyboard, display, switches, LEDs
**I/O Interfaces** 
- Enable a processor to receive or transmit info
- provide a mechanism for communication
	- transmission medium may be wired or wireless
	- Communication interface may be serial or parallel
	- control, status, and data can be exchanged
We use two types of I/O
- External - devices not included on FPGA
	- Solenoids, relays, etc.
	- ADC converters
- Internal - IP included on FPGA

**Accessing I/O Devices**
- I/O Mapping provides dedicated memory map for I/O
- We use pointers... that's the tldr

**THE DATA THAT THE POINTER IS POINTING TO IS 16 BITS - THE POINTER ITSELF IS AND WILL ALWAYS BE 32 BITS**
```C
#define BASE_ADDRESS 0x12345678
uint16* my_device = (uint16*)BASE_ADDRESS;
```

Read from pointer
```C
#define BASE_ADDRESS 0x12345678
volatile uint16* dev = (uint16*)BASE_ADDRESS;

// read device and store in variable
data = *dev;
```

Write to address
```C
#define BASE_ADDRESS 0x12345678
volatile uint16* dev = (uint16*)BASE_ADDRESS;

// read device and store in variable
*dev = data;
```

With REG_OFFSET
```C
#define BASE_ADDRESS 0x12340000
#define REG2_OFFSET 1
uint16* dev = (uint16*)BASE_ADDRESS;

// write data to device
*(dev + REG2_OFFSET) = data;
```
Each address is a byte, so if we started at 0x12340000 and add one, we move to 0x12340002
