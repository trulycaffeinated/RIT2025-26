# Buffers and FIFO

Buffers are the most used data structure within Embedded system software - also implemented in hardware

Waterlines - too little data for buffer or too much data for buffer

As buffering increases...
Buffer size (physical) increases
Latency increases
Timing tolerance - the ability to manage time on both sides - increases
- The ability of your system to be tolerant of random timings
Memory size increases (expensive but ability to buffer is good)
Code Complexity increases
